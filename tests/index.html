Notes

Blended evaluation needs the on-device model, which is roughly 25 MB and is downloaded from a public CDN. The rule-engine evaluation needs no download and is the mode the Node runner measures with node tests/run-node.js --eval.

The dataset in data/evaluation-data.js was written and labelled by the project author. It is a development set for catching regressions, not an independent benchmark.
